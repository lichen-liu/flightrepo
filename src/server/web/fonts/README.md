# Fonts

Manrope (variable, weights 200–800) and DM Mono (weights 400 and 500) are the
shared boboji.fyi fonts. These WOFF2 files match the assets used by Trip Split
and AeroRepo; they are served locally and retain their SIL Open Font Licenses.

- Manrope: `OFL-Manrope.txt`
- DM Mono: `OFL-DMMono.txt`
